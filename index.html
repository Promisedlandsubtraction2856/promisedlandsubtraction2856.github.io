📦 What Is This?

Codex-deepseek is a smart wrapper that lets you run the real OpenAI Codex CLI, but point it to DeepSeek models for actual execution. This means you can use the powerful Codex interface with DeepSeek's cost-effective AI backend.

The magic part? We create a completely isolated environment, so your original ChatGPT Desktop app and the standard codex command keep their own logins and settings. No conflicts, no overwrites.

✨ Why You'll Love It

🔒 Zero Interference

Your ChatGPT login stays untouched. We use a separate CODEX_HOME folder.

🚀 One-Command Setup

Installers for Windows, macOS, and Linux – just run one command, you're done.

💰 Save Money

DeepSeek models are incredibly affordable compared to OpenAI GPT-4. Same Codex workflow, lower cost.

🧠 Full Codex Power

All original Codex features are preserved – code generation, editing, file manipulation, exec committee – all work seamlessly.

🔧 System Requirements

  • Any modern OS: Windows 10/11, macOS 12+, or any mainstream Linux distribution (Ubuntu, Fedora, DEBIAN, etc.)
  • Node.js v18 or higher (installed separately)
  • Git (recommended, but not strictly required)
  • A DeepSeek API key – you can get one from DeepSeek's platform. The installer will ask for it.
  • At least 50MB free disk space for the app and its cache.

❓ Step-by-Step Setup Guide

🪟 Windows

  1. Download the windows_installer.ps1 file from the release page.
  2. Right-click the file, choose "Run with PowerShell" if available; otherwise open PowerShell manually.
  3. If you see a policy error, run Set-ExecutionPolicy RemoteSigned -Scope CurrentUser first, then retry.
  4. When prompted, paste your DeepSeek API key. Done!

🍎 macOS / 🐧 Linux

  1. Download the install.sh script.
  2. Open your terminal, navigate to the Downloads folder: cd ~/Downloads
  3. Make it executable: chmod +x install.sh
  4. Run it: ./install.sh
  5. Enter your DeepSeek API key when asked. Finished!

🧰 Troubleshooting & Common Questions

💡 "I see 'codex: command not found'"

If the installation completed but your terminal doesn't recognize codex, you likely need to restart your terminal or add the Node.js bin folder to your PATH. After reinstalling, open a fresh terminal window.

💡 "How do I switch back to my original ChatGPT Codex?"

Simple – your original Codex installation was never touched. Just run your old command, or remove this wrapper from your PATH. You'll still have your original setup intact.

💡 "Can I use DeepSeek models with other AI tools?"

This repository is specifically designed for OpenAI Codex CLI. For other tools, you might need different integrations. Check DeepSeek's official documentation for general API access.

📚 Additional Features

  • Isolated Config: All settings stored in ~/.codex-deepseek/ – never interferes with your main ~/.codex/ folder.
